# CS F429 — Part 2: Biomedical NER on BC5CDR (CRF baseline)

Chemical / Disease named-entity recognition with a linear-chain CRF, plus error analysis, a CLI demo and the Part 2 report.

**Official CRF result (test set, entity level, exact match):** P 0.8642 · R 0.7579 · **F1 0.8076** (c1 = 0.1, c2 = 0.01).
Chemical F1 0.8489, Disease F1 0.7583. Dictionary-lookup baseline: F1 0.6787.

## 1. Setup (2 minutes)

Needs Python 3.9+ (tested on 3.13). From this folder:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

`seqeval` is **not** needed (it fails to build on some machines; we ship our own `ner_metrics.py`, verified to reproduce the official numbers exactly).

## 2. Quick start

```bash
python run_all.py --demo
```

Runs everything in ~1 minute: data pipeline → trains the CRF → dictionary baseline → error analysis → table generation →
**checks that the test F1 equals the official 0.8076** → runs the CLI demo.

Just want the demo (the trained model is already included in `models/`)?

```bash
python ner_cli.py --demo
python ner_cli.py --text "Patients treated with cisplatin developed nephrotoxicity and hearing loss."
python ner_cli.py            # interactive: type sentences, empty line or Ctrl-D to quit
```

## 3. What each file does

| File | Purpose |
|---|---|
| `data_pipeline.py` | `data_raw/*.json` (integer tags) → validated BIO `data/{train,dev,test}.json` + statistics. Offline, no extra packages. |
| `crf_baseline.py` | Features, training, tuning (`--tune`), evaluation, saves `models/crf_bc5cdr.crfsuite` and `crf_test_predictions.json`. `--verbose` shows the L-BFGS training log. |
| `ner_metrics.py` | Entity-level P/R/F1 (seqeval/conlleval rules), no dependencies. |
| `ner_cli.py` | **The demo.** Extracts chemical and disease mentions from text (`--text`, `--file`, pipe, interactive, `--json`, `--demo`, `--retrain`). Auto-trains if the model file is missing. |
| `dictionary_baseline.py` | Dictionary-lookup lower bound (F1 0.6787). |
| `error_analysis.py` | Error taxonomy, recall by length / frequency / surface form, confusion matrices, examples → `results/`, `figures/`, `report/tables/`. |
| `run_all.py` | One command that runs and verifies everything. |
| `report/main.tex`, `report/main.pdf` | The Part 2 report (LaTeX source and compiled PDF, 9 pages). |
| `results/` | `crf_metrics.json`, `error_analysis.json`, `error_examples.md`, `dictionary_baseline.json` |
| `CRF_paramater_tuning_results.txt` | The original 9-combination dev-set grid search log. |

## 4. Demo script for the viva (about 5 minutes)

1. **Training live** — `python crf_baseline.py --verbose` (about 25 s). Shows dataset sizes, the CRFsuite training log, then dev and test results. Say: *trained on 5,228 training sentences only; c1/c2 chosen on dev; test used once.*
2. **Extraction** — `python ner_cli.py --demo`. Chemicals and diseases are marked inline and listed with character offsets.
3. **Your own text** — `python ner_cli.py` and type a sentence from an abstract.
4. **Show an honest failure** (examiners like this): type
   `Haloperidol was given to control agitation in a patient with Parkinson's disease.`
   → *Parkinson's disease* is missed (despite 20 training mentions) and `Aspirin can cause gastric ulcers.` returns only *ulcers*. Link it to the error analysis: boundary/modifier errors and context effects.
5. **Error analysis headline** — recall is 0.498 on entity strings never seen in training vs 0.971 on frequent ones; unseen strings cause 78.7% of errors; abbreviations have recall 0.461; length matters mostly because long entities are rarely seen. Figures are in `figures/`.

## 5. Rebuilding the report

The compiled `report/main.pdf` is included. To rebuild: `cd report && latexmk -pdf main.tex` (the tables are generated by `error_analysis.py` and `report/make_tables.py`, so run `run_all.py` first if you change anything).
On Overleaf: upload this whole folder as a zip, and set `report/main.tex` as the main document (it loads figures from `../figures`).
**Before submitting, fill in the group number and member names on the title page** (placeholder in `\author{}`).

## 6. Troubleshooting

- **`pip install` fails building `python-crfsuite`** — upgrade pip (`python -m pip install -U pip`) so a prebuilt wheel is used; on very new/old Python versions, use Python 3.10–3.13.
- **`ModuleNotFoundError: sklearn_crfsuite`** — the virtual environment isn't active, or `pip install -r requirements.txt` was not run.
- **`No trained model` / model missing** — `ner_cli.py` trains it automatically (~25 s), or run `python crf_baseline.py`.
- **Numbers differ slightly from 0.8076** — shouldn't happen (training is deterministic); `run_all.py` prints `CHECK FAILED` if it does. Make sure `data/*.json` weren't modified.
- Colours in the CLI are automatic on a terminal; force off with `--color off`.
